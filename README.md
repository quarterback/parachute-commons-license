# Parachute Commons License (PCL) 2.0

**🪂 A license that deploys protection as the stakes get closer to the ground.**

The Parachute Commons License starts from a premise most licenses dodge: a
license is governance infrastructure. It should be legible, opinionated, and
designed for the people actually using it. PCL is **graduated** — fully
permissive at small scale, contributory at commercial scale, and protective
against a narrow set of abusive uses at any scale.

This is a **source-available / fair-code** license. It is deliberately **not**
OSI-approved "open source," because it conditions some uses on fair
contribution and preserved provenance. Don't call works under it "open source"
without that qualification.

## The three phases

- **Phase One — packed.** Anyone may read, share, adapt, and build on the Work
  for free, as long as they preserve provenance (credit the original creator,
  link back, keep the license). This applies fully and indefinitely to everyone
  below the Threshold.
- **Phase Two — deployed.** When a **Threshold Entity** (roughly: $1M revenue,
  $1M raised, or 50+ people) makes commercial or institutional use, added terms
  apply: visible acknowledgment, fair contribution back, derivative
  transparency, and permission for automated ingestion at scale.
- **Phase Three — emergency.** A narrow set of uses are prohibited for everyone:
  impersonation, falsifying the work's intent, provenance laundering, and
  facilitating unlawful harm.

## What changed from 1.0

PCL 1.0 (2025) was a manifesto with the right instincts and soft edges. 2.0
keeps the parachute metaphor and the three-phase structure, and adds what a
real license needs to actually operate:

- **Defined terms** — Work, Threshold Entity, Commercial Use, Automated
  Ingestion at Scale, Provenance, etc.
- **A concrete threshold** — a bright line ($1M revenue / $1M raised / 50 FTE)
  instead of vibes, so a user can tell which phase they're in.
- **Procedure** — grace periods, cure windows, termination and reinstatement,
  and what "fair contribution" actually means in practice.
- **The standard legal spine** — patent grant, trademark reservation, warranty
  disclaimer, limitation of liability, severability, versioning.
- **Honest positioning** — explicitly fair-code, not "open source," so no one is
  misled about OSI status or downstream compliance.

The enforcement philosophy is unchanged: PCL is enforceable as a copyright
license **and** maintained through community norms. Legal remedy and community
correction are both on the table; using one doesn't waive the other.

## How to use it

1. Copy the `LICENSE` file from this repo, verbatim, into your project.
2. Add the notice (see the end of the `LICENSE` file) to your README and key
   files.
3. Optionally adjust the Threshold in Section 1.7 for your project and state the
   change in your notice.

## A note on scope

PCL governs **works** broadly — methodologies, writing, designs, data, and code
— not only software. That's deliberate: the extraction problems it responds to
(erosion of authorship, collapse of attribution, ingestion without provenance)
aren't unique to code.

## Why this exists

It responds to the erosion of authorship in hyper-replicable environments, the
collapse of clear attribution in contemporary knowledge systems, and the need
for shared work to stay open without being quietly extracted at scale.

*It is a parachute, not a gate. A signal, not a straitjacket.*

PCL is not legal advice. If you're licensing something high-stakes, have a
