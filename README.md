# Parachute Commons License (PCL) 2.0

**🪂 A license that deploys protection as the stakes get closer to the ground.**

The Parachute Commons License starts from a premise: a software license is governance
infrastructure. It should be legible, opinionated, and designed for the people
actually using it. PCL is graduated — permissive at small scale, contributory
at commercial scale, and protective against a narrow set of abusive uses at any
scale.

PCL is a source-available, fair-code license.

## The three phases

- **Phase One — packed.** Anyone may read, share, adapt, and build on the Work
  for free, as long as they preserve provenance: credit the original creator,
  link back, and keep the license. This applies fully and indefinitely to
  everyone below the Threshold.
- **Phase Two — deployed.** When a **Threshold Entity** (roughly: $1M revenue,
  $1M raised, or 50+ people) makes commercial or institutional use, added terms
  apply: visible acknowledgment, fair contribution back, derivative
  transparency, and permission for automated ingestion at scale.
- **Phase Three — emergency.** A narrow set of uses are out of bounds for
  everyone: impersonation, falsifying the work's intent, provenance laundering,
  and facilitating unlawful harm.

## What changed from 1.0

PCL 1.0 (2025) set out the parachute metaphor and the three-phase structure. 2.0
keeps both and adds what a license needs to operate:

- **Defined terms** — Work, Threshold Entity, Commercial Use, Automated
  Ingestion at Scale, Provenance.
- **A concrete threshold** — $1M revenue / $1M raised / 50 FTE, so a user can
  tell which phase they're in.
- **Procedure** — grace periods, cure windows, termination and reinstatement,
  and what "fair contribution" means in practice.
- **The legal spine** — patent grant, trademark reservation, warranty
  disclaimer, limitation of liability, severability, versioning.

The enforcement philosophy carries over: PCL is enforceable as a copyright
license and maintained through community norms. Legal remedy and community
correction are both available.

## How to use it

1. Copy the `LICENSE` file from this repo, verbatim, into your project.
2. Add the notice (at the end of the `LICENSE` file) to your README and key
   files.
3. Optionally adjust the Threshold in Section 1.7 for your project and state the
   change in your notice.
